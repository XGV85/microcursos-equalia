# Microcursos Equalia

Materiales descargables y páginas de lecciones de los microcursos de Equalia,
publicados vía GitHub Pages para poder enlazarse desde Masteriyo (WordPress) sin
depender de ningún equipo local.

## Estructura

Una carpeta por curso, y dentro una carpeta por lección:

```
<curso>/
  leccion-N/
    *.pdf               # materiales descargables de esa lección
    leccionN_*.html     # página de lección autocontenida, si la hay
    logo_equalia_*.png  # logo real de marca (nunca recrear con CSS)
```

Las rutas **no se cambian nunca** una vez publicadas: los botones de descarga de
los ítems de Masteriyo apuntan a estas URL exactas.

## Lo que no vive aquí

Los **vídeos** no se publican en este repositorio (pesan entre 28 y 129 MB): van
a YouTube y se enlazan desde Masteriyo. Los **ítems** (resumen, caso práctico,
actividad, autoevaluación, bibliografía) se pegan directamente en Masteriyo como
bloques HTML, no se sirven desde aquí.
