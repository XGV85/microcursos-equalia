# Microcursos Equalia

Páginas de lecciones interactivas de los microcursos de Equalia, publicadas vía
GitHub Pages para poder incrustarse en Masteriyo (WordPress) sin depender de
ningún equipo local.

## Estructura

```
<curso>/
  <leccion>/
    leccionN_....html   # página de la lección (autocontenida)
    logo_equalia_*.png  # logo real de marca (nunca recrear con CSS)
    checklist_*.pdf     # materiales descargables, si aplica
```

## Cursos
